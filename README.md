# ELEC1005 Assignment 2 - Volunteer Safety Response App

## Project Overview

This repository contains the source files and documentation for our ELEC1005 Assignment 2 Power Apps project.

The app supports community safety volunteers by allowing users to report hazards, managers to view incidents, assign volunteers, and volunteers to accept or decline assigned incidents.

## Main Features

- Report Hazard screen
- SharePoint data storage
- GPS and submitted time capture
- Manager Dashboard with access code
- Latest 4 incident display
- Incident detail view
- Assign Volunteer workflow
- My Assignments screen
- Accept / Decline assignment
- Directions screen for accepted incidents

## Technology Used

- Microsoft Power Apps
- SharePoint Lists
- Power Fx
- GitHub
- Power Platform CLI

## SharePoint Lists

- List 1: Incidents
- Volunteers
- Assignments
